# 功能实用性复核 · 2026-11-26

检查对象是当前路由和用户可见功能。评估依据是能否完成一个任务、结果能否追溯、出错时用户是否知道如何继续。没有访问量、留存率或用户访谈数据，所以这里评价任务价值和实现表现，不能推出用户采用率。

| 功能 | 能解决的问题与验证 | 取舍与改进 |
|---|---|---|
| 匿名 Demo、总览、账户 | 从公开 Demo 打开预填工作区，展开金额，进入资料、组合、模拟和助手。注册与登录有前端和后端测试。 | 求职演示首选 Demo，README 已改为直达入口。实名用户注册、账户恢复及付费模型本轮没有做线上端到端验证。|
| 资料与风险评分 | 在隔离的演示会话保存虚构年龄，重新计算风险代理分数，再用七股示例构建组合。 | 保留给愿意填写资料的用户；分数对应调查中的风险资产持有比例，不能据此判断客户适当性。|
| 优化、历史比较、计算回执 | 同一股票池连续运行 40% 和 35% 持仓上限。旧版第二次请求仍携带页面打开时的权重。修正后，每次成功保存的权重都成为同股票池下一次的参考；失败运行不会更新参考。 | 这是主线。历史窗口、等权基准、换手和回撤要随结论展示。参考组合比较与滚动策略回测分别解读。|
| 三情形模拟、持仓导入 | 对当前组合实际运行三个情形。此前逐文件验证 OCR、人工确认、CSV 与模拟金额传递。 | 保留快捷模拟。高级波动模型适合研究；本轮没有重新估计其长期预测准确率。复杂报表仍需人工核对。|
| 固定任务助手 | 在匿名 Demo 用保存的组合运行解释任务，收到含计算证据的答复。 | 任务明确定义时优先使用，能追溯到数值工具。|
| 研究 Agent | 线上验证解读组合、试算上限和获取试算回执。自然语言存在歧义，离线挑战复现了把“以前的试算”和否定表达误判为新试算。 | 新网页默认只读；用户允许试算后，规划器才有机会选择对照计算。本次仅在实际生成试算回执时显示所用上限。旧 API 请求保持原有契约。|
| 文库检索 | 从文库检索微软 FY2026 营业利润，核对命中结果含 SEC 文件链接。此前评测另有不支持问题的拒答记录。 | 对收录的公司、年份和指标有用。超出文库的问题应说明证据不足。|
| 本地 MCP、旧目录 | MCP 通过本地客户端测试，适合展示外部工具接入。市场、新闻、规划器等旧页面未注册在现有路由。 | MCP 放在开发者材料；旧目录不算已上线产品功能。|

下一阶段用既有误判作为训练任务。[离线实验](../evals/intent/README.md)给出了训练、规则对照、工具限制后的误判及所有失败例。优先补独立用户表述，再决定是否微调更大的模型。真实用户完成率、不同券商模板的覆盖率、真实模型长期费用与可靠性仍需分别验证。
