## 数学模型与决策

| 模块 | 为什么使用 | 审查结果与处理 |
| --- | --- | --- |
| ExtraTrees 家庭画像 | 拟合人口特征与资产持有比例的非线性关系 | 保留已有模型与按家庭分组的训练/测试拆分。目标是 2022 SCF 中风险资产持有占比，并非心理风险承受能力或股票推荐比例。已有验证为未加权单次留出；完整调查权重、多重插补统计推断仍有局限，不以修改界面或未经独立验证的重训冒充精度提升。 |
| 均值收缩 | 降低短样本下噪声较大资产均值的影响 | 保留逐资产不确定性启发式；不声称最优或无偏。 |
| Ledoit–Wolf 协方差 | 稳定估计资产风险及共同波动 | 保留收缩估计、对称半正定与可行约束检查。 |
| 最低方差/收益目标优化及有效前沿 | 在用户选择的股票和仓位上限内求解明确的估计方差目标 | 保留只做多、权重和为一、同一持仓上限及可行收益目标；最低方差模式不使用收益偏好。 |
| 滚动评估 | 检查先训练后评价的表现，并与朴素基线比较 | 保留前 60 月训练、固定最近 24 月评价，等权/最低方差/当前参考权重使用同日期、调仓及费用；历史不足则不声称有时间外结果。 |
| 联合循环块重采样 | 同时抽取各股票三个月回报块，保留共同变化和短期模式 | 作为快速默认；修正结果元信息，使其报告实际抽样的经验均值/波动，而非未用于抽样的收缩均值。不能生成样本未包含的新危机。 |
| 正态收益 | 为常数波动提供透明的比较基线 | 保留，并明确简单正态的低于 −100% 抽样会截断为全部损失，改变尾部矩。 |
| GARCH(1,1) | 对波动聚集作敏感性比较 | 历史模式继续以月度对数收益做受平稳约束的 Gaussian QML 拟合；至少 60 点。手动模式原先使用简单收益递推，现改为与拟合模式一致的正价格过程，先转换为对数方差，并按情景一致地调整长期方差；手动 α=.1、β=.85 是假设而非拟合。 |
| 参数化对数正态 | 检验用户自己的均值和波动假设，并保持正价格 | 保留；明确有效年预期收益与年化对数波动尺度，区别于正态/统计模式的算术年化。默认不同资产独立不能视为真实相关性。 |
| 现金流与实际财富 | 月末收支、完成一年后增加固定付款、终值除以累积通胀 | 保留原有计算；新增独立于外部现金流的投资回撤，原有余额回撤继续单独显示。提款导致的余额减少不再暗示为投资损失。 |
| 蒙特卡洛目标/耗尽概率 | 统计有限路径中的事件频率 | 新增 95% Wilson 抽样区间，0%/100% 抽样结果也不会显示为完全确定。区间仅表示抽样误差，不包括参数、数据和模型不确定性。 |
| 旧版历史绩效端点 | 兼容历史接口 | 修正 Sortino：按全部月份计算相对于月度最低可接受收益的下行二阶矩；使用有效年无风险利率换算月利率；零分母返回 null。区分投资 CAGR 和含提款的余额增长率。历史组合实际跟踪持仓漂移并按所选频率调仓，提款频率单独控制；校验权重并拒绝缺失月份拼接。固定权重 performance 端点明确月度调仓口径。 |

三情景是人为敏感性设定：年化算术回报 ±1 个百分点；非历史模型波动 ×0.9 / ×1.1。参数化对数正态的 mu 则按有效年均值 ±1 个百分点处理。同一随机种子使对照共享创新；情景没有被估计出的发生概率。分位数是每个情景内部的分布，不等同于三个情景。

网页组合与模拟器均增加 **Why these models? Methods and limitations**，用户可直接查看选择原因和边界。

## 数据与范围

用户本轮确认“暂时没有数据源，先完成其他修改”。因此没有更新 CSV，也没有伪造新价格或修改 Calibration 日期。研究数据仍为原始 CSV 的月度聚合，截止 **2025-02-28**。用户最初要求的上周五为 **2026-10-23**；即使日线覆盖该日，月度拟合也应最多使用 **2026-09-30** 的完整月份。默认 60 个月只是滚动窗口长度，并不说明数据最新。

既有 CSV 导入、版本化发布与校验流程保留。后续来源需覆盖当前股票池，口径一致，缺失不得前填；不能只替换少量股票以改变截止日期。

生产当前关闭可选 AI 扩展。本地没有 `AI_related` 的新闻情绪/对话等实现和模型，因此未宣称审计或验证这些外部模型；它们未被启用。本次覆盖现有核心计算、训练代码及保留的历史绩效接口，未修改其他网站。

本地 Python 54、Node 26、React 22，共 **102 项测试通过**；生产前端构建通过。回归包括三情景展示/切换、现金流与投资回撤分离、Wilson 边界、Sortino、提款不影响投资 CAGR、持有不调仓与月调仓的数值区别、GARCH 可复现和正价格，以及原有约束与无未来数据泄漏检查。
