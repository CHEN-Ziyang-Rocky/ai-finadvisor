# 求职展示审查与修补（2026-10-29）

## 结论

适合作为全栈开发、后端开发或金融科技研发岗位的在线作品。完整链路包含登录及会话校验、个人输入、统计学习推断、受约束组合优化、滚动历史评估、三情景模拟、数据版本和数据库持久化。可以展示工程实现和研究方法判断。

建议将项目定位为“Portfolio research application / 投资组合研究演示”。风险画像模型预测的是调查家庭实际持有风险资产的比例；没有证明它能测量个人心理风险承受能力。组合的历史优势和模拟结果也不构成未来业绩证据。用于量化研究岗位时，应另准备点时数据、更多时间外/市场外检验和研究论证。

七姐妹定义与股份类别参考 [Schwab 的发行人列表](https://www.schwab.com/learn/story/what-are-magnificent-7-stocks)。请求解析漏洞及修复版本见 [GHSA-27r3-jxmh-p828](https://github.com/advisories/GHSA-27r3-jxmh-p828)。

最高收益端点的处理依据是线性收益在有限持仓单纯形上的极值：高于边界收益的资产必须取上限，低于边界的资产取零，只有边界收益相同的资产可以重新分配。对这些剩余自由权重最小化同一个二次方差目标，保留原收益目标和全部持仓约束。这解决退化不等式的数值问题，没有回退为无约束权重或隐藏失败。

## 检查范围与证据

- 白盒检查：核心路由、会话与账号归属、资料/组合保存事务、输入校验、前端加载与历史状态、数据来源/月末处理、估计/优化、滚动评估和模拟的核心实现。
- 本地回归：后端 29 项、React 26 项、Python 70 项，共 125 项通过；生产构建及接口地址检查通过。
- 新克隆复现：在不含原始行情 CSV、训练工作簿、模型 pickle、真实环境文件及密钥的发布检出中运行全部 70 项 Python 测试通过。生产不会使用测试数据。
- 真实行情：七姐妹各有最新完整 60 个月共同回报（2021-10-31—2026-09-30）；两种分配方式均满足非负、权重和为 1、单股不超过 50%；24 个滚动评估月的训练末日均早于评估月。
- 三模型：Historical、Statistical（GARCH）及 Parameterized，各 500 路径、10 年、三情景，返回有限且可序列化结果。
- 依赖：本轮修补后，前端/后端 npm 运行依赖审计和已安装 Python 核心/生产环境审计均为无已知漏洞。这不是零风险或渗透测试证明。
- 生产验证：发布有源文件/依赖回退副本，核对原有应用文件版本；仅重启 Finance 两个服务，保留生产公钥及旧静态资源，没有修改 Nginx、systemd、共享 MySQL 配置和其他站点。

独立的线上验收账号使用虚构资料，验证注册、登录、完整资料校验、模型推断、七姐妹优化、24 月评估、按用户隔离、组合重载、三情景模拟和登出后令牌失效。该账号与其测试记录在验收后清理。生产浏览器检查示例按钮、七个选项及页面显示。

## 仍需诚实说明的局限

1. **构建工具技术债。** React 官方已弃用 Create React App，当前 react-scripts 仍用于构建和测试。本次完整前端 npm 审计有 37 个开发依赖条目（16 low、6 moderate、15 high），运行依赖审计为 0。开发工具问题不能用“线上无漏洞”一笔带过；后续应将构建和测试迁至维护中的工具。此次没有为消除审计数字强行跨版本替换整个工具链。[React 官方说明](https://react.dev/blog/2025/02/14/sunsetting-create-react-app)
2. **首屏体积。** 主 JS 包约 693 kB gzip，尚未按路由拆分。可以正常展示，但弱网络下的加载和交互仍有优化空间；没有做真实用户性能统计。
3. **数据与结论边界。** 股票范围来自固定历史清单，存在选择/存续偏差；免费来源可能修订、限流或中断，不能保证长期供给或行情再分发权限。当前记录截至 2026-10-23，研究按完整月截至 2026-09-30。见[完整历史说明](FULL-HISTORY-UPDATE-2026-10-29.zh-CN.md)。
4. **模型证据。** 已发布训练记录为 3,596 / 900 个训练/测试家庭，家庭无重叠，MAE 约 19.3/100，R² 约 0.317。属于未加调查权重的家庭留出验证，没有个人置信区间、收益预测准确率或经过验证的投资适当性结论。
5. **运行保障。** 目前为个人演示部署、单机服务和内存会话，服务重启后需要重新登录；没有完成负载容量测量、独立安全渗透测试、跨机故障恢复演练和可用性 SLA。共享基础设施改造须另行批准。
6. **旧扩展。** 旧新闻、聊天和其他 AI_related 集成默认关闭，不是本轮已验收的成品功能。requirements.txt 中的额外旧集成依赖没有作为完整运行环境验收；核心以 requirements-core/production 为准。

这些局限不妨碍将已经验证的核心研究流程用于个人作品展示，但面试时应说明取舍、证据和下一步，不宣传真实交易连接、稳定超额收益或企业级就绪。

## 招聘方复现与演示

先看 [在线项目](https://finance.imrocky.com/user)，注册自己的账号并使用虚构资料。进入 Portfolio Research，估计画像、加载 Magnificent Seven、优化并查看约束/历史比较，再进入 Monte Carlo Simulator 对照三情景。不要共享真实个人财务资料或共用公开账号。

源代码检查无需原始市场数据：

```sh
npm ci --prefix backend
npm ci --prefix frontend
npm test --prefix backend
CI=true npm test --prefix frontend -- --watchAll=false --runInBand
npm run build --prefix frontend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-data.txt
.venv/bin/python scripts/test-python.py
```

完整本地应用需要另行准备合法来源的研究行情及本地训练模型，参见 [数据准备](DATA-SETUP.md)。测试夹具不会被写为应用默认数据，也不能当作真实回报。
